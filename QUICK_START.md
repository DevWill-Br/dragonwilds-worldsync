# Quick Start

## Create a shared world
1. Open the app
2. Click **Assistente Inicial / Initial Wizard**
3. Choose **Create shared world**
4. Select:
   - synchronized folder
   - local save folder
   - the `.sav` world from the list
5. Finish setup

## Join an existing shared world
1. Open the app
2. Click **Assistente Inicial / Initial Wizard**
3. Choose **Join existing shared world**
4. Select:
   - synchronized folder
   - local save folder
5. Load the existing world metadata
6. Save configuration

## During use
- type your name
- click **Host World**
- open the game
- after playing, close the game
- click **End Host**
- wait for sync completion
