# Installation Guide

## Option 1 — run the script version
Use:
- `src/Abrir Dragonwilds WorldSync.bat`

## Option 2 — build the executable
Use:
- `src/Compilar EXE.bat`

## Requirements
- Windows
- PowerShell
- RuneScape: Dragonwilds installed
- access to a synchronized folder solution
  - OneDrive recommended for the tutorial flow
